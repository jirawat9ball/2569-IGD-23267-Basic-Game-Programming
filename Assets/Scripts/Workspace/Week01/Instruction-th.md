# Assignment 01: การประกาศตัวแปร, ชนิดข้อมูลพื้นฐาน และการเชื่อมต่อกับ Unity Editor สำหรับ Game Development

## 📋 ภาพรวมของ Assignment

เรียนรู้พื้นฐานที่สำคัญที่สุดของการเขียนโปรแกรมด้วยภาษา C# บน Unity Engine ซึ่งประกอบด้วย **การประกาศตัวแปร (Variables)**, **ชนิดข้อมูลพื้นฐาน (Data Types: int, float, bool, string)**, **ชนิดข้อมูลเฉพาะของ Unity (Vector3, Color, GameObject, Component)**, **ระดับการเข้าถึงและการแสดงผลใน Inspector (Access Modifiers & `[SerializeField]`)**, ตลอดจนการทำงานร่วมกับฟังก์ชันวงจรชีวิตของ Unity อย่าง **`Start()`** และ **`Update()`**

นอกจากนี้ Assignment นี้ยังมีส่วนของการฝึกปฏิบัติสร้างฉากสิ่งแวดล้อม 3D ด้วยเครื่องมือ **Terrain** และการประกอบระบบผู้เล่นมุมมองบุคคลที่หนึ่ง (First Person Controller) เพื่อให้เห็นภาพการนำโค้ดไปใช้งานจริงในเกม

---

## 🎯 จุดประสงค์การเรียนรู้

- เข้าใจหลักการทำงาน ชนิด และขนาดของข้อมูลพื้นฐานในภาษา C# (`string`, `int`, `float`, `bool`)
- เข้าใจการควบคุมการมองเห็นและการแก้ไขตัวแปรผ่าน Unity Inspector ด้วย `public`, `private` และ `[SerializeField]`
- สามารถใช้งานชนิดข้อมูลของ Unity เช่น `Vector3`, `Color`, `GameObject`, `Transform` และ Custom Component
- เข้าใจความแตกต่างระหว่างการอ้างอิงวัตถุในฉาก (Scene Object / Hierarchy) กับวัตถุที่เป็นแม่แบบ (Prefab / Project Asset)
- สามารถดำเนินการทางคณิตศาสตร์พื้นฐาน (`+`, `-`, `*`, `/`, `%`) และการเชื่อมต่อข้อความ (String Concatenation)
- เข้าใจการทำงานของวงจรชีวิต Unity: `Start()` ทำงานรอบเดียวตอนเริ่ม และ `Update()` ทำงานซ้ำทุกเฟรม
- เข้าใจการจับเวลาแบบ Frame-rate Independent ด้วย `Time.deltaTime`
- มีทักษะการสร้างและตกแต่งฉาก 3D เบื้องต้นด้วย Unity Terrain

### โจทย์ระดับ 1: ข้อมูลและสถานะพื้นฐานของตัวละคร (Primitive Types)

**วัตถุประสงค์:** แสดงความเข้าใจชนิดข้อมูลพื้นฐาน 4 ชนิดในภาษา C# สำหรับการเก็บข้อมูลสเตตัสตัวละคร

**ตัวแปรที่ต้องสร้าง:**
1. `characterName` ชนิด `string` - ชื่อของตัวละคร
2. `level` ชนิด `int` - ระดับเลเวล
3. `moveSpeed` ชนิด `float` - ความเร็วในการเคลื่อนที่
4. `isAlive` ชนิด `bool` - สถานะว่ายังมีชีวิตอยู่หรือไม่

**💡 แนวทางการเขียนโค้ด (Guideline):**
- ตรวจสอบการสะกดชื่อตัวแปรให้ตรงตามตัวพิมพ์เล็ก-พิมพ์ใหญ่ (Case-sensitive) เช่น `characterName` และ `moveSpeed`
- สำหรับตัวแปรชนิด `float` สามารถกำหนดค่าเริ่มต้นได้โดยใส่ตัวอักษร `f` ต่อท้ายตัวเลข เช่น `5.5f`
- สำหรับ `bool` มีค่าเป็นไปได้เพียง `true` หรือ `false`

**Test Cases ที่ตรวจสอบ:**
- `As01_Check_CharacterName`: ตรวจสอบว่ามีตัวแปร `characterName` ชนิด `string`
- `As02_Check_Level`: ตรวจสอบว่ามีตัวแปร `level` ชนิด `int`
- `As03_Check_MoveSpeed`: ตรวจสอบว่ามีตัวแปร `moveSpeed` ชนิด `float`
- `As04_Check_IsAlive`: ตรวจสอบว่ามีตัวแปร `isAlive` ชนิด `bool`

**Game Context:** หน้าต่าง Profile และค่าสถานะพื้นฐานของตัวละครในเกมแนว Action / RPG

## ⚙️ ส่วนที่ 2: การเขียนโค้ดการทำงาน (Logic ใน `Start` และ `Update`)

### 1. ภายในฟังก์ชัน `Start()`
ฟังก์ชัน `Start()` จะถูกเรียกทำงานเพียง **ครั้งเดียว** เมื่อเริ่มเข้าสู่เกม ให้เขียนการทำงานต่อไปนี้:

1. **แสดงชื่อตัวละคร:**
   - ใช้ `Debug.Log()` แสดงข้อความพร้อมค่าของตัวแปร `characterName`
2. **ตั้งค่าพลังชีวิตเริ่มต้น:**
   - นำค่าของ `maxHealth` ไปกำหนดให้แก่ตัวแปร `currentHealth`
3. **การดำเนินการทางคณิตศาสตร์และข้อความ:**
   - ใช้ `Debug.Log()` แสดงผลการคำนวณต่อไปนี้ทีละบรรทัด:
     - `NAME + LASTNAME` (การเชื่อมต่อ String)
     - `HP - DAMAGE` (การลบ)
     - `SPEED * TIME` (การคูณ)
     - `DISTANCE / TIME` (การหาร)
     - `HP % DAMAGE` (การหารเอาเศษ / Modulo)
4. **กำหนดตำแหน่งและเปลี่ยนสีตัวละคร:**
   - กำหนดตำแหน่งปัจจุบันของวัตถุ `transform.position` ให้เท่ากับ `StartPosition`
   - เรียกคำสั่งเปลี่ยนสีผ่านคอมโพเนนต์ C2: `C2.SetColorCapsule(colorPlayer, playerMesh);`

**💡 แนวทางการเขียนโค้ด (Guideline):**
- การเชื่อมข้อความและตัวแปรใน `Debug.Log()` ใช้เครื่องหมาย `+` เช่น `Debug.Log("Character: " + characterName);`
- ตรวจสอบให้แน่ใจว่าได้กำหนดค่า `currentHealth = maxHealth;` ก่อนเริ่มการต่อสู้หรือประมวลผลใดๆ

---

### 2. ภายในฟังก์ชัน `Update()`
ฟังก์ชัน `Update()` จะถูกเรียกทำงานซ้ำ **ทุกๆ เฟรม (Frame-by-Frame)** ให้เขียนการทำงานต่อไปนี้:

1. **การจับเวลาตามเวลาจริง:**
   - เพิ่มค่าให้กับตัวแปร `timer` อย่างต่อเนื่องในทุกเฟรมโดยบวกด้วย `Time.deltaTime` (`timer += Time.deltaTime;`)
2. **การตรวจสอบเงื่อนไขเวลา:**
   - ใช้คำสั่ง `if` ตรวจสอบว่าเวลาผ่านไปแล้วอย่างน้อย 3 วินาทีหรือไม่ (`timer >= 3f`)
   - **เมื่อเงื่อนไขเป็นจริง:**
     - ใช้ `Debug.Log()` แสดงข้อความแจ้งเตือน เช่น `"Timer 3 seconds reached!"`
     - **รีเซ็ตค่าตัวแปร `timer` ให้กลับเป็น `0f`** เพื่อเริ่มนับรอบใหม่

**💡 แนวทางการเขียนโค้ด (Guideline):**
- ห้ามใช้ตัวเลขคงที่บวกเพิ่มใน `timer` เช่น `timer += 1` เพราะจะทำให้ความเร็วขึ้นอยู่กับ Frame Rate ของเครื่อง ให้ใช้ `Time.deltaTime` เสมอ
- การรีเซ็ตค่าตัวแปร `timer = 0f;` ต้องเขียนไว้ภายในบล็อก `{ ... }` ของคำสั่ง `if`

## 🏔️ ส่วนที่ 3: การสร้างฉากและการส่งงาน (Terrain & Video Submission)

นอกเหนือจากการเขียนโค้ดและการทดสอบผ่าน Test Runner แล้ว นักศึกษาต้องดำเนินภารกิจภาคปฏิบัติดังนี้:

```
┌─────────────────────────────────────────────────────────────┐
│                    ขั้นตอนการส่งงาน Week 01                 │
│                                                             │
│ 1. สร้างฉาก Terrain  ➔  2. จัดวางตัวละคร  ➔  3. บันทึกวิดีโอ  │
│    (ปั้นเขา / ใส่สี)       (FPC Controller)     (เดินสำรวจฉาก) │
└─────────────────────────────────────────────────────────────┘
```

1. **สร้างฉากสภาพแวดล้อมด้วย Terrain:**
   - สร้างวัตถุ Terrain ในฉาก `Assets/Scenes/Week01_Value.unity`
   - ใช้เครื่องมือ Sculpt ปั้นภูมิประเทศ (ภูเขา, เนินเขา, หุบเขา)
   - ลงสีพื้นผิว (Texture Painting) เช่น พื้นหญ้า ดิน หรือหิน
   - (ตัวเลือกเสริม) ตกแต่งด้วยต้นไม้หรือพุ่มไม้ตามความสวยงาม
2. **นำตัวละครลงฉากและตั้งค่า:**
   - นำตัวละคร First Person Controller มาจัดวางบนพื้นผิวฉากให้อยู่ในตำแหน่งที่เหมาะสม
   - ตรวจสอบว่าได้ลาก Component และ Prefab ใส่ในช่อง Inspector ของ `Assignment_Student_Week01` ครบถ้วนทุกช่อง
3. **ทดสอบใน Play Mode:**
   - กดปุ่ม Play เพื่อเริ่มเล่นเกม
   - สังเกตว่าตัวละครถูกย้ายตำแหน่งไปยัง `StartPosition` และเปลี่ยนสีตาม `colorPlayer` หรือไม่
   - ทดลองเดินสำรวจรอบๆ ภูมิประเทศที่ได้สร้างขึ้น
4. **บันทึกคลิปวิดีโอ (Screen Record):**
   - อัดคลิปวิดีโอหน้าจอขณะกำลังอยู่ใน Play Mode
   - บันทึกให้เห็นการเดินสำรวจฉาก Terrain และแสดงคอนโซลที่แสดง Log การคำนวณและตัวจับเวลา
5. **การส่งงาน:**
   - อัปโหลดคลิปวิดีโอผลงานและส่งไฟล์งานตามขั้นตอนที่ผู้สอนกำหนด

## ⚠️ ข้อควรระวังและ Best Practices

1. **Case-Sensitivity ในภาษา C#:** การตั้งชื่อตัวแปรต้องตรงตามที่โจทย์กำหนดทุกตัวอักษร เช่น `SpawnHeart` ไม่ใช่ `spawnheart`
2. **Scene Object vs Asset Prefab:**
   - ตัวแปร `Heart` ต้องลากจากหน้าต่าง **Project** เท่านั้น
   - ตัวแปร `SpawnHeart`, `C1`, `C2`, `playerMesh` ต้องลากจากหน้าต่าง **Hierarchy** เท่านั้น
3. **การใช้ Time.deltaTime:** ต้องบวกสะสมเวลาด้วย `Time.deltaTime` เสมอ เพื่อให้การนับเวลาตรงตามวินาทีจริง ไม่ขึ้นกับความเร็วเฟรมเรต
4. **การรีเซ็ต Timer:** อย่าลืมตั้งค่า `timer = 0f;` เมื่อเงื่อนไข `timer >= 3f` ทำงาน ไม่เช่นนั้นเงื่อนไขจะเป็นจริงซ้ำทุกเฟรมหลังจากครบ 3 วินาที
