# 📸 คำสั่งส่งภาพสกรีนช็อต — Week 03

## 📋 คำชี้แจง

นักศึกษาต้องส่งภาพสกรีนช็อตจำนวน **3 ภาพ** เพื่อยืนยันว่าโค้ดที่เขียนสามารถทำงานได้จริงใน Unity Editor โดยแต่ละภาพต้องแสดงทั้ง **Game View** และ **Console Log** ที่แสดงผลลัพธ์ของโปรแกรม

> [!IMPORTANT]
> ภาพสกรีนช็อตทุกภาพ **ต้องแสดงทั้ง Game View และ Console Log** ให้เห็นชัดเจนในภาพเดียวกัน

---

## 📸 ภาพที่ 1: As03 — การสุ่มสร้างไอเทม (Random Item Drop)

**ข้อที่เกี่ยวข้อง:** `As03_RandomItemDrop`

**สิ่งที่ต้องแสดงในภาพ:**
- ✅ **Game View:** แสดง GameObject ไอเทมที่ถูก Instantiate ขึ้นมาในฉากที่ตำแหน่ง (0, 3, 0)
- ✅ **Console Log:** แสดงข้อความ `Got item : <ชื่อไอเทม>` เช่น `Got item : Coin`

**ตัวอย่างผลลัพธ์ที่คาดหวังใน Console:**
```
Got item : Coin
```

**วิธีทดสอบ:**
1. ตรวจสอบว่า Inspector ของ `Assignment_Student_Week03` มีการลาก Prefab ไอเทมใส่ช่อง `items` Array แล้ว
2. กด Play ใน Unity Editor
3. สังเกตว่ามีไอเทมถูกสร้างขึ้นใน Game View และ Console แสดงชื่อไอเทมที่สุ่มได้
4. จับภาพสกรีนช็อต

---

## 📸 ภาพที่ 2: As07 — การสร้างศัตรูเป็นแถว (Instantiate Enemies)

**ข้อที่เกี่ยวข้อง:** `As07_InstantiateEnemies`

**สิ่งที่ต้องแสดงในภาพ:**
- ✅ **Game View:** แสดง GameObject ศัตรูที่ถูก Instantiate ขึ้นมาเรียงกันบนแกน X (ตำแหน่ง x = 1, 2, 3, ...)
- ✅ **Console Log:** แสดงข้อความบอกตำแหน่งของศัตรูแต่ละตัว

**ตัวอย่างผลลัพธ์ที่คาดหวังใน Console (ค่าเริ่มต้น HpEnemy = {10, 20, 30}):**
```
new enemy at position x = 1
new enemy at position x = 2
new enemy at position x = 3
```

**วิธีทดสอบ:**
1. ตรวจสอบว่า Inspector ของ `Assignment_Student_Week03` มีการลาก Prefab ศัตรูใส่ช่อง `Enemy` แล้ว
2. ตรวจสอบว่า `HpEnemy` Array มีค่าอยู่ (ค่าเริ่มต้น: {10, 20, 30})
3. กด Play ใน Unity Editor
4. สังเกตว่ามีศัตรูถูกสร้างเรียงกันใน Game View
5. จับภาพสกรีนช็อต

---

## 📸 ภาพที่ 3: As09 — การเคลื่อนที่ไปหาเป้าหมาย (Move to Target)

**ข้อที่เกี่ยวข้อง:** `As09_MoveToTarget`

**สิ่งที่ต้องแสดงในภาพ:**
- ✅ **Game View:** แสดงตัวละคร (character) ที่เคลื่อนที่ไปถึง (หรือใกล้ถึง) ตำแหน่งเป้าหมาย (positionToMove)
- ✅ **Console Log:** แสดงตำแหน่ง x ที่เปลี่ยนไปในแต่ละเฟรม (ทศนิยม 2 ตำแหน่ง) และเวลารวม

**ตัวอย่างผลลัพธ์ที่คาดหวังใน Console (speed = 10, target x = 3):**
```
1.00
2.00
3.00
Time : 0
```

**วิธีทดสอบ:**
1. ตรวจสอบว่า Inspector ของ `Assignment_Student_Week03` มีการลาก Transform ของตัวละครใส่ช่อง `character` และ Transform ของเป้าหมายใส่ช่อง `positionToMove` แล้ว
2. ตั้งค่า `speed` ตามต้องการ (ค่าเริ่มต้น: 10)
3. กด Play ใน Unity Editor
4. รอจนตัวละครเคลื่อนที่ถึงเป้าหมายและ Console แสดง `Time : <เวลา>`
5. จับภาพสกรีนช็อต
