# 🎥 คำสั่งส่งคลิปวิดีโอ (VDO) — Week 06: การใช้งานไอเทมในเกม (Item Usage)

## 📋 คำชี้แจง

ให้นักศึกษา**บันทึกคลิปวิดีโอหน้าจอ (Screen Recording)** ความยาวประมาณ 10–30 วินาที เพื่อแสดงให้เห็นการทำงานของระบบไอเทม (Item System) ตามแลคเชอร์ในคลาสแบบ Real-time ใน Unity Editor โดยต้องเห็นผลลัพธ์ทั้งใน **Game View** และ **Console Log** ควบคู่กันอย่างชัดเจน

> [!IMPORTANT]
> คลิปวิดีโอต้องบันทึกให้เห็นทั้ง **Game View** (การเคลื่อนที่ของ Player ไปเก็บไอเทม) และหน้าต่าง **Console Log** (ข้อความ Log ที่เด้งขึ้นมาแบบ Real-time) ให้เห็นชัดเจนตลอดการทดสอบ

---

## 🎬 ลำดับเหตุการณ์ที่ต้องแสดงในคลิปวิดีโอ (Scenario)

```
[ 1. กด Play ▶️ ] ───> [ 2. เดินไปเก็บไอเทม 🧪 ] ───> [ 3. ไอเทมหาย + Console เด้ง Log 💬 ]
```

1. **เริ่มต้น:** กดปุ่ม **Play ▶️** ใน Unity Editor เพื่อเริ่มรันเกม
2. **การเคลื่อนที่:** กดปุ่ม **W, A, S, D** หรือ **ปุ่มลูกศร** เพื่อบังคับตัวละคร Player เดินบน Grid
3. **การเก็บไอเทม (Trigger Event):**
   - บังคับ Player เดินเข้าไปเหยียบ/ชนช่องที่มีไอเทม **Potion** (ยาฟื้นฟูพลังงาน)
4. **ผลลัพธ์ที่ต้องเกิดขึ้นในวิดีโอ:**
   - ✅ **Game View:** ไอเทม Potion หายไปจากฉากทันทีเมื่อชน (`Destroy(gameObject)`)
   - ✅ **Console Log:** มีข้อความเด้งขึ้นมาตามลำดับอย่างชัดเจน:
     1. `[Trigger] Potion collided with Player` (ตรวจจับการชนผ่าน `OnTriggerEnter2D`)
     2. `Picked up Potion! +10 Energy` (ข้อความจากการเก็บไอเทม `ItemPotion`)
     3. `Healed +10! Current Energy: <ตัวเลข>` (ข้อความยืนยันการเพิ่มพลังงานจาก `player.Heal()`)

> 💡 **ส่วนเสริม (Bonus / HW):** หากทำไอเทมดาบ (`ItemSword`) หรือส่วนอื่นๆ สามารถเดินเก็บดาบและแสดง Log `Picked up Sword! +10 Attack` ต่อในคลิปเดียวกันได้เลย

## 🛠️ เครื่องมือแนะนำสำหรับการอัดวิดีโอหน้าจอ

- **Windows Game Bar (ติดมากับ Windows ทุกเครื่อง):**
  - กดปุ่ม `Win + Alt + R` เพื่อเริ่มบันทึก / หยุดบันทึกทันที
  - หรือกด `Win + G` เพื่อเปิดแผงควบคุมการบันทึก
- **OBS Studio:** สำหรับตั้งค่าบันทึกหน้าต่างโปรแกรม Unity โดยเฉพาะ
- **ShareX / Bandicam / Loom:** โปรแกรมอัดหน้าจอฟรีอื่นๆ

| หัวข้อ | รายละเอียด |
|---|---|
| **ความยาวคลิป** | สั้นกระชับ 10 – 30 วินาที |
| **รูปแบบไฟล์** | `.mp4` หรือ `.mov` (หรือแนบลิงก์ Google Drive / YouTube Unlisted ตามระบบ) |
| **การตั้งชื่อไฟล์** | `รหัสนักศึกษา_Week06_Item.mp4` (เช่น `66012345_Week06_Item.mp4`) |

> [!WARNING]
> **ข้อควรระวังและเกณฑ์การให้คะแนน:**
> - ❌ คลิปที่ไม่มีหน้าต่าง Console Log หรือมองไม่เห็นตัวหนังสือจะถูกหักคะแนน
> - ❌ กรุณาเคลียร์หน้าต่าง Console (กดปุ่ม Clear) ก่อนกดเริ่มอัด เพื่อให้เห็น Log ที่เกิดขึ้นใหม่ได้ชัดเจน
> - ❌ ห้ามใช้คลิปวิดีโอของผู้อื่นโดยเด็ดขาด

> [!TIP]
> **เคล็ดลับการจัดหน้าต่าง:**
> จัด Layout ใน Unity โดยลากหน้าต่าง **Game View** ไว้ฝั่งซ้าย และหน้าต่าง **Console** ไว้ฝั่งขวา เพื่อให้เห็นการเล่นและ Log ที่ขึ้นมาพร้อมๆ กันได้อย่างชัดเจน
