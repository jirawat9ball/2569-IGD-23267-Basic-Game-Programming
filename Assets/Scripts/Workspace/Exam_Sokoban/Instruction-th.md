ทำเกมดันกล่อง (Sokoban) เล็ก ๆ ที่เล่นได้จริงในฉาก — ผู้เล่นเดินทีละช่อง ดันกล่องไปวางบนเป้าหมายให้ครบทุกช่องแล้วชนะ

ข้อสอบนี้ต่อยอดจากเรื่องสร้างแผนที่ด้วย Nested Loop (Week 04–05) มี 4 ข้อ

| 3 | ดันกล่อง + ตรวจว่าชนะ | 35 |
| 4 | **โบนัส** พื้นถล่ม | 15 |
| | **รวม** | **85 + โบนัส 15 = 100** |

เขียนโค้ดทั้งหมดในไฟล์ `Exam_Student_Sokoban.cs` ตรงที่มี `// Guideline:` บอกไว้

## ⚠️ อ่านก่อนเริ่ม

- **ติดข้อไหน ให้คอมเมนต์ส่วนที่ยังเขียนไม่เสร็จทิ้งก่อน** ถ้ามี compile error (ตัวแดงใน Console) แม้แต่บรรทัดเดียว ระบบจะรันเทสไม่ได้เลยทุกข้อ = ได้ 0 คะแนน
  ไฟล์ที่ให้มาคอมไพล์ผ่านตั้งแต่แรก (เมธอดที่ต้องคืนค่ามี `return false;` รอไว้แล้ว)
- **ห้ามลบหรือเปลี่ยนชื่อ** ตัวแปร / เมธอด / Prefab ที่ให้มา ระบบตรวจเรียกใช้ตามชื่อ

  - `SetColor(go, สี)` เปลี่ยนสี Sprite
  - `SetSortingOrder(go, เลข)` ตั้งลำดับการวาด เลขมากอยู่บน

## 🗺️ แผนที่และกติกาพิกัด (อ่านให้เข้าใจก่อนเขียนข้อ 1)

แผนที่เก็บเป็น `string[] map` บรรทัดละ 1 แถว ทุกแถวยาวเท่ากัน

| สัญลักษณ์ | ความหมาย |
|---|---|
| `#` | กำแพง |
| `.` | พื้น |
| `P` | ผู้เล่น (มีพื้นอยู่ข้างใต้) |
| `B` | กล่อง (มีพื้นอยู่ข้างใต้) |
| `X` | เป้าหมาย |

ด่านตัวอย่าง (อยู่ในตัวแปร `map` แล้ว)

```text
          col: 0123456789
map[0]         ##########
map[1]         #........#
map[2]         #..B..X..#
map[3]         #..P.....#
map[4]         #.....B..#
map[5]         #..X.....#
map[6]         ##########
```

### กติกาพิกัด

- `map[0]` คือ **แถวบนสุด** ของด่าน
- ช่อง `map[row][col]` อยู่ในฉากที่ **`new Vector2(col, rows - 1 - row)`** ห่างกันช่องละ 1 หน่วย

> **จุดที่คนพลาดบ่อย:** ใน array เราเขียน `[row][col]` (แถวก่อน คอลัมน์ทีหลัง) แต่ในฉากเราเขียน `Vector2(x, y)` (แนวนอนก่อน แนวตั้งทีหลัง)
> และ row นับ **ลงล่าง** แต่ y ในฉากนับ **ขึ้นบน** — เลยต้องกลับด้านด้วย `rows - 1 - row`

ตัวอย่างจากด่านข้างบน (`rows = 7`)

| ช่องใน map | ตัวอักษร | ตำแหน่งในฉาก |
|---|---|---|
| `map[2][3]` | `B` | `Vector2(3, 7 - 1 - 2)` = **(3, 4)** |
| `map[5][3]` | `X` | `Vector2(3, 7 - 1 - 5)` = **(3, 1)** |

กล่องกับเป้าหมายอยู่คอลัมน์เดียวกัน (x = 3) แต่กล่องอยู่แถวที่ 2 (สูงกว่า) เลยได้ y = 4 ส่วนเป้าหมายอยู่แถวที่ 5 (ต่ำกว่า) ได้ y = 1

**หลังจากอ่านแผนที่เสร็จ ข้อมูลทั้งหมดในไฟล์ (`isWall`, `boxes`, `playerPos` ฯลฯ) ใช้ index แบบ `[x, y]` ตามพิกัดในฉาก** แปลงแค่ครั้งเดียวตอนอ่าน map แล้วที่เหลือใช้ x, y ตลอด
ทำให้ทิศ `Vector2Int.up` = `(0, 1)` บวกเข้าไปได้ตรง ๆ = ขึ้นบนในฉาก

## ข้อ 1 — ทำฉาก (25 คะแนน)

```csharp
public void BuildLevel(string[] map)
```

- ใช้ Nested Loop อ่านแผนที่ทีละตัวอักษร แล้ว `Instantiate` ของตามสัญลักษณ์ ที่ตำแหน่งตามกติกาพิกัดข้างบน
- ในแต่ละช่องสร้างของดังนี้

| ตัวอักษร | สร้างอะไร | เก็บข้อมูลอะไร |
|---|---|---|
| `#` | กำแพง (สุ่มจาก `wallTiles`) **ไม่ต้องมีพื้น** | `isWall[x, y] = true` |
| `.` | พื้น (สุ่มจาก `floorTiles`) | `floors[x, y]` |
| `P` | พื้น + ผู้เล่นจาก `playerPrefab` | `floors[x, y]`, `player`, `playerPos` |
| `B` | พื้น + กล่องจาก `boxPrefab` | `floors[x, y]`, `boxes[x, y]` |
| `X` | `targetPrefab` **แทนพื้น** (ไม่ต้องสร้างพื้นซ้อน) แล้ว `SetColor(..., Color.yellow)` | `floors[x, y]`, `isTarget[x, y] = true` |

- กล่องเรียก `SetSortingOrder(กล่อง, 2)` ผู้เล่นเรียก `SetSortingOrder(ผู้เล่น, 3)` ให้วาดทับพื้น

## ข้อ 2 — ควบคุมตัวละคร + รับอินพุต (25 คะแนน)

```csharp
void Update()
public bool TryMove(Vector2Int direction)
```

**`TryMove`** — ลอจิกการเดิน
- เดิน **ทีละ 1 ช่อง** ต่อการเรียก 1 ครั้ง (ขยับเป็นช่อง ๆ แบบเกมโปเกมอน ไม่ใช่เดินลื่น)
- ช่องถัดไปเป็นกำแพง หรืออยู่นอกแผนที่ → ไม่ขยับ `return false`
- เดินได้ → อัปเดต `playerPos` และย้าย `player.transform.position` ไปช่องใหม่ แล้ว `return true`

**`Update`** — รับอินพุต
- อ่านปุ่มด้วย `Input.GetKeyDown` ทั้ง **ลูกศร** และ **WASD** (ขึ้น = ↑ หรือ W, ลง = ↓ หรือ S, ซ้าย = ← หรือ A, ขวา = → หรือ D)
- กดแล้วเรียก `TryMove(ทิศ)` ถ้าเดินได้ให้เรียก `IsSolved()` ต่อ

> **ต้องแยกลอจิกกับอินพุตออกจากกัน:** อ่านปุ่มใน `Update` เท่านั้น ส่วนการเดินต้องอยู่ใน `TryMove` เท่านั้น
> ระบบตรวจจะเรียก `TryMove` ตรง ๆ โดยไม่กดปุ่ม ถ้าเขียนการเดินไว้ใน `Update` จะไม่ได้คะแนน

## ข้อ 3 — ดันกล่อง + ตรวจว่าชนะ (35 คะแนน)

เพิ่มใน `TryMove`: ถ้าช่องถัดไปมีกล่อง ให้ดู **ช่องหลังกล่อง** อีกชั้น
- ช่องหลังกล่องเป็นพื้นหรือเป้าหมาย และไม่มีกล่องอื่น → กล่องเลื่อน 1 ช่อง ผู้เล่นเดินตามไปช่องที่กล่องเคยอยู่ `return true`
- ช่องหลังกล่องเป็นกำแพง / นอกแผนที่ / มีกล่องอีกใบ → **ไม่ขยับทั้งคู่** `return false`
- ตอนดันให้ย้ายกล่องใบเดิม (อัปเดตทั้ง `boxes` และ `transform.position`) ห้าม Instantiate กล่องใหม่

```csharp
public bool IsSolved()
```
- ทุกช่องที่เป็นเป้าหมายมีกล่องทับอยู่ → `Debug.Log("You Win");` แล้ว `return true`
- ยังมีเป้าหมายว่างอย่างน้อย 1 ช่อง → `return false` (ห้ามพิมพ์ `You Win`)

## ข้อ 4 — โบนัส: พื้นถล่ม (15 คะแนน)

ทำงานเฉพาะตอน `collapseMode` เป็น `true` ถ้าเป็น `false` ต้องทำงานเหมือนข้อ 3 ทุกอย่าง

- หลังเดินสำเร็จ ช่องที่ผู้เล่น **เพิ่งเดินออกมา** กลายเป็นหลุม → `isHole[x, y] = true` และลบพื้นช่องนั้นด้วย `RemoveObject(floors[x, y])`
- ผู้เล่นเดินลงหลุมไม่ได้ → `return false`
- ดันกล่องลงหลุมไม่ได้ → `return false` ไม่ขยับทั้งคู่

## ❓ เคสที่อาจสงสัย

| คำถาม | คำตอบ |
|---|---|
| ผู้เล่นยืนบนเป้าหมายได้ไหม | **ได้** |
| ดันกล่องที่อยู่บนเป้าหมายออกไปอีกได้ไหม | **ได้** (หลังดันออก `IsSolved()` ก็กลับเป็น `false`) |
| ดันกล่อง 2 ใบที่ติดกันพร้อมกันได้ไหม | **ไม่ได้** ดันได้ทีละใบ |
| เดินถอยหลังแล้วกล่องตามมาไหม (ดึงกล่อง) | **ไม่** กล่องขยับได้แค่ตอนโดนดัน |
| เดินชน / ดันไม่ได้ ต้องมีอะไรขยับไหม | **ไม่ขยับอะไรเลย** ทั้งผู้เล่นและกล่อง และ (ข้อ 4) ไม่เกิดหลุม |
| นอกแผนที่นับเป็นอะไร | นับเป็นกำแพง เดินออกไม่ได้ (ต้องเช็คก่อนอ่าน array ไม่งั้น error) |
| เรียก `IsSolved()` ซ้ำหลายครั้งได้ไหม | ได้ พิมพ์ `You Win` ทุกครั้งที่คืน `true` |
| ข้อ 4: ถ้าเดินออกจากช่องเป้าหมาย ช่องนั้นถล่มไหม | **ถล่ม** เหมือนช่องอื่น (ด่านนั้นจะผ่านไม่ได้แล้ว เป็นส่วนหนึ่งของความยากในโหมดนี้) |
| ข้อ 4: ดันกล่องแล้วช่องไหนถล่ม | ช่องที่ **ผู้เล่น** เดินออกมา (กล่องไม่ทำให้พื้นถล่ม) |
